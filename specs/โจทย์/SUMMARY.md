# สรุปโจทย์ของแต่ละทีม

## ภาพรวม

โจทย์ทั้งหมดเป็นเว็บแอปหน้าเดียว ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ต้องใช้ Framework และไม่ต้องทำระบบหลังบ้าน โดยมีเวลาพัฒนา 1 ชั่วโมง 15 นาที

## สรุปโจทย์แต่ละทีม

| ทีม | แอปที่ต้องทำ | สิ่งสำคัญที่ต้องมี |
| --- | --- | --- |
| ทีม 1 | แอปบันทึกรายรับ-รายจ่าย | เพิ่ม แก้ไข และลบรายการได้, แยกรายรับกับรายจ่าย, แสดงยอดรวมและยอดคงเหลือ, ข้อมูลไม่หายเมื่อรีเฟรชหน้า |
| ทีม 2 | แอปบัตรคำศัพท์ | เพิ่มบัตรคำได้, กดพลิกดูคำแปล, เลื่อนไปบัตรก่อนหน้า/ถัดไป, ทำเครื่องหมายว่าจำได้หรือยังจำไม่ได้, แสดงความคืบหน้า |
| ทีม 3 | แอปนาฬิกาโฟกัส | นับถอยหลังรอบโฟกัสและรอบพัก, เริ่ม หยุด และรีเซ็ตเวลาได้, บันทึกประวัติรอบที่จบ, ป้องกันการกดเริ่มซ้ำ |
| ทีม 4 | แอปติดตามนิสัย | เพิ่มนิสัยได้, แสดงตารางวันจันทร์ถึงวันอาทิตย์, กดเลือกวันที่ทำสำเร็จแล้ว, สรุปผลรายสัปดาห์, รีเซ็ตสัปดาห์ใหม่ได้ |
| ทีม 5 | แอปรายการหนังที่อยากดู | เพิ่มหนังได้, ค้นหาชื่อหนัง, กรองเรื่องที่ดูแล้วหรือยังไม่ได้ดู, ให้คะแนน 1-5 ดาว, ล้างรายการที่ดูจบแล้ว |
| ทีม 6 | แอปรายการซื้อของพร้อมงบ | เพิ่มสินค้าได้, จัดกลุ่มตามหมวดหมู่, ทำเครื่องหมายว่าหยิบแล้ว, คำนวณราคารวม, เตือนเมื่อเกินงบ |
| ทีม 7 | แอปเกมตอบคำถาม | ตอบคำถาม 5 ข้อ, แจ้งว่าตอบถูกหรือผิด, แสดงคะแนนรวม, ทบทวนข้อที่ตอบถูกหรือผิด, เก็บคะแนนสูงสุด |
| ทีม 8 | แอปสมุดรายชื่อผู้ติดต่อ | เพิ่มผู้ติดต่อได้, ค้นหาชื่อหรือเบอร์โทร, กรองตามกลุ่ม, ทำเครื่องหมายรายการโปรด, แก้ไขและลบรายชื่อได้ |
| ทีม 9 | แอปบอร์ดจัดการงาน | เพิ่มงานได้, แสดงงานใน 3 ช่อง: รอทำ กำลังทำ และเสร็จแล้ว, ย้ายงานด้วยปุ่มลูกศร, กรองตามความสำคัญ, แสดงความคืบหน้า |
| ทีม 10 | แอประบบสั่งเครื่องดื่ม | แสดงเมนูอย่างน้อย 6 รายการ, เลือกร้อน เย็น หรือปั่น, เพิ่มลงตะกร้า, เพิ่มหรือลดจำนวนแก้ว, ยืนยันคำสั่งซื้อและล้างตะกร้าได้ |
| ทีม 11 | แอปติดตามการดื่มน้ำ | กดบันทึกปริมาณน้ำแบบเร็วได้, ตั้งเป้าหมายต่อวัน, แสดงแถบความคืบหน้า, แสดงประวัติพร้อมเวลา, เริ่มวันใหม่ได้ |
| ทีม 12 | แอปคลังสูตรอาหาร | เพิ่มสูตรอาหารได้, กรอกวัตถุดิบหลายบรรทัด, ค้นหาชื่อเมนู, กรองตามประเภทอาหาร, กดดูรายละเอียดสูตร, ทำเครื่องหมายเมนูโปรด |
