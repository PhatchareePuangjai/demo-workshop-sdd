# Specification: Web Mini Kanban Board Application (บอร์ดจัดการงานแบบคัมบัง)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันบอร์ดคัมบังขนาดเล็ก เพื่อช่วยให้ผู้ใช้มองเห็นสถานะของงานทั้งหมดในภาพเดียวว่างานไหนรอทำ กำลังทำ หรือเสร็จแล้ว และเลื่อนงานข้ามคอลัมน์ได้ง่าย

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มการ์ดงาน (Create)

- ผู้ใช้สามารถพิมพ์ชื่องานใหม่แล้วกดเพิ่มการ์ดเข้าสู่คอลัมน์ "รอทำ" ได้ทันที (รองรับการกด Enter)
- ผู้ใช้สามารถเลือกระดับความสำคัญของงานได้ 3 ระดับ: "สูง", "กลาง", "ต่ำ" โดยแสดงเป็นสีที่ต่างกันบนการ์ด
- ระบบไม่อนุญาตให้เพิ่มการ์ดที่ชื่องานเป็นค่าว่าง

### 2.2 การดูและกรองบอร์ด (Read & Filter)

- แสดงบอร์ด 3 คอลัมน์: "รอทำ (To Do)", "กำลังทำ (Doing)", "เสร็จแล้ว (Done)"
- แต่ละคอลัมน์ต้องแสดงจำนวนการ์ดที่อยู่ในคอลัมน์นั้นบนหัวคอลัมน์
- มีตัวกรองให้เลือกดูการ์ดตามความสำคัญ: "ทั้งหมด", "สูง", "กลาง", "ต่ำ"
- แสดงตัวเลขสรุปความคืบหน้าแบบเรียลไทม์ เช่น "เสร็จแล้ว 4 จาก 10 งาน (40%)"

### 2.3 การย้ายและแก้ไขการ์ด (Update)

- แต่ละการ์ดมีปุ่มลูกศรสำหรับย้ายไปคอลัมน์ก่อนหน้าหรือคอลัมน์ถัดไป
- การ์ดที่อยู่ในคอลัมน์ "เสร็จแล้ว" ต้องแสดงผลให้ต่างจากการ์ดอื่นอย่างชัดเจน (เช่น ขีดฆ่าหรือปรับสีให้จางลง)
- ผู้ใช้สามารถแก้ไขชื่องานและระดับความสำคัญของการ์ดที่มีอยู่แล้วได้

### 2.4 การลบการ์ด (Delete)

- สามารถลบการ์ดทีละใบได้
- มีปุ่ม "ล้างงานที่เสร็จแล้ว" สำหรับลบการ์ดทั้งหมดในคอลัมน์ "เสร็จแล้ว" พร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลการ์ดและคอลัมน์ที่การ์ดอยู่ต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: บนคอมพิวเตอร์แสดง 3 คอลัมน์เรียงข้างกัน ส่วนบนสมาร์ตโฟนให้เรียงต่อกันในแนวตั้งหรือเลื่อนแนวนอนได้
- **Boundary Case**: การ์ดในคอลัมน์แรกต้องย้ายถอยหลังไม่ได้ และการ์ดในคอลัมน์สุดท้ายต้องย้ายไปข้างหน้าไม่ได้ (ปิดปุ่มหรือไม่ทำงาน)
- **Long Text Handling**: กรณีชื่องานยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบการ์ด
- **Empty Column**: คอลัมน์ที่ไม่มีการ์ดต้องแสดงข้อความบอกสถานะ เช่น "ยังไม่มีงานในคอลัมน์นี้"
- **Empty State**: หากยังไม่มีการ์ดใดบนบอร์ด ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "บอร์ดยังว่างอยู่ เพิ่มงานแรกของคุณได้เลย!"
