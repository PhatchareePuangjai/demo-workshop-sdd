# Specification: Web Contact Book Application (สมุดรายชื่อผู้ติดต่อ)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสมุดรายชื่อผู้ติดต่อ เพื่อช่วยให้ผู้ใช้เก็บข้อมูลติดต่อของเพื่อน ครอบครัว และที่ทำงานไว้ในที่เดียว ค้นหาได้เร็ว และทำเครื่องหมายคนสำคัญไว้ด้านบนสุด

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มผู้ติดต่อ (Create)

- ผู้ใช้สามารถกรอกชื่อ-นามสกุล, เบอร์โทรศัพท์, อีเมล และกลุ่ม (เช่น "เพื่อน", "ครอบครัว", "ที่ทำงาน") แล้วกดบันทึกได้
- ระบบไม่อนุญาตให้บันทึกผู้ติดต่อที่ชื่อว่างหรือเบอร์โทรศัพท์ว่าง
- หากกรอกอีเมล ต้องมีเครื่องหมาย "@" จึงจะบันทึกได้ พร้อมแจ้งข้อความผิดพลาดที่ชัดเจน

### 2.2 การดู ค้นหา และกรองรายชื่อ (Read, Search & Filter)

- แสดงรายชื่อผู้ติดต่อเรียงตามตัวอักษรของชื่อ โดยรายการโปรดแสดงอยู่ด้านบนสุด
- มีช่องค้นหาที่กรองรายชื่อจากชื่อหรือเบอร์โทรศัพท์ได้ทันทีขณะพิมพ์
- มีตัวกรองให้เลือกดูตามกลุ่ม: "ทั้งหมด", "เพื่อน", "ครอบครัว", "ที่ทำงาน"
- แสดงตัวเลขสรุปแบบเรียลไทม์ เช่น "ผู้ติดต่อทั้งหมด 12 คน (รายการโปรด 3 คน)"

### 2.3 การแก้ไขและทำเครื่องหมาย (Update)

- ผู้ใช้สามารถกดปุ่มรูปดาวเพื่อทำเครื่องหมาย "รายการโปรด" และรายการโปรดต้องถูกจัดแสดงไว้ด้านบนสุดเสมอ
- ผู้ใช้สามารถแก้ไขข้อมูลของผู้ติดต่อที่บันทึกไว้แล้วได้ทุกช่อง
- แต่ละรายชื่อต้องแสดงป้ายกำกับกลุ่มให้เห็นชัดเจน

### 2.4 การลบผู้ติดต่อ (Delete)

- สามารถลบผู้ติดต่อทีละรายการได้ โดยมีการถามยืนยันก่อนลบ
- มีปุ่ม "ล้างรายชื่อทั้งหมด" สำหรับลบผู้ติดต่อทุกคนพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลผู้ติดต่อทั้งหมดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **No Search Result**: หากค้นหาแล้วไม่พบรายชื่อที่ตรงกัน ต้องแสดงข้อความแจ้ง เช่น "ไม่พบผู้ติดต่อที่ค้นหา"
- **Long Text Handling**: กรณีชื่อหรืออีเมลยาวมาก ข้อความต้องขึ้นบรรทัดใหม่หรือย่ออย่างสวยงาม ไม่ล้นหลุดขอบจอ
- **Empty State**: หากยังไม่มีผู้ติดต่อ ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีรายชื่อ เริ่มบันทึกผู้ติดต่อคนแรกของคุณได้เลย!"
