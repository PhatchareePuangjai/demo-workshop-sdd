# Specification: Web Habit Tracker Application (ติดตามนิสัยประจำวัน)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับติดตามนิสัยที่ต้องการทำให้ได้ทุกวัน (เช่น ออกกำลังกาย อ่านหนังสือ) เพื่อช่วยให้ผู้ใช้เห็นความสม่ำเสมอของตัวเองตลอดสัปดาห์และมีแรงจูงใจในการทำต่อเนื่อง

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มนิสัย (Create)

- ผู้ใช้สามารถพิมพ์ชื่อนิสัยใหม่และกดเพิ่มเข้าสู่ลิสต์ได้ทันที (รองรับการกด Enter)
- ระบบไม่อนุญาตให้เพิ่มนิสัยที่เป็นค่าว่าง

### 2.2 การดูตารางประจำสัปดาห์ (Read & Filter)

- แสดงผลเป็นตาราง โดยแถวคือนิสัยแต่ละอัน และคอลัมน์คือวันจันทร์ถึงวันอาทิตย์
- ช่องของวันที่ทำสำเร็จแล้วต้องแสดงสีหรือเครื่องหมายถูกที่เห็นชัดเจน แตกต่างจากช่องที่ยังไม่ได้ทำ
- มีตัวกรองให้เลือกดู 2 มุมมอง: "ทั้งหมด" และ "เฉพาะที่ยังทำไม่ครบ"
- แสดงตัวเลขสรุปแบบเรียลไทม์ เช่น "สัปดาห์นี้ทำสำเร็จแล้ว 12 จาก 21 ครั้ง (57%)"

### 2.3 การเปลี่ยนสถานะและแก้ไข (Update)

- ผู้ใช้สามารถคลิกที่ช่องของวันใดก็ได้ เพื่อสลับสถานะ "ทำแล้ว" หรือ "ยังไม่ได้ทำ"
- แต่ละแถวแสดงจำนวนวันที่ทำสำเร็จของนิสัยนั้น เช่น "5/7 วัน"
- ผู้ใช้สามารถแก้ไขชื่อนิสัยที่มีอยู่แล้วได้

### 2.4 การลบนิสัย (Delete)

- สามารถลบนิสัยทีละรายการได้ โดยมีการถามยืนยันก่อนลบ
- มีปุ่ม "รีเซ็ตสัปดาห์ใหม่" สำหรับล้างเครื่องหมายการทำสำเร็จทั้งหมดโดยที่ยังเก็บรายชื่อนิสัยไว้

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลนิสัยและสถานะของแต่ละวันต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: บนหน้าจอสมาร์ตโฟน ตารางต้องยังอ่านได้และกดเลือกช่องได้สะดวก โดยอนุญาตให้เลื่อนตารางในแนวนอนได้
- **Today Highlight**: คอลัมน์ของวันปัจจุบันต้องถูกเน้นให้เห็นชัดว่าคือวันนี้
- **Long Text Handling**: กรณีชื่อนิสัยยาวมาก ข้อความต้องไม่ทำให้ตารางเสียรูปหรือล้นหลุดขอบจอ
- **Empty State**: หากยังไม่มีนิสัยใด ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีนิสัยที่ติดตาม เริ่มสร้างนิสัยดี ๆ อันแรกของคุณได้เลย!"
