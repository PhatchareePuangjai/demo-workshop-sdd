# Specification: Web Pomodoro Focus Timer Application (นาฬิกาจับเวลาโฟกัส)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันจับเวลาแบบ Pomodoro เพื่อช่วยให้ผู้ใช้โฟกัสกับงานเป็นช่วง ๆ สลับกับการพักผ่อน พร้อมบันทึกว่าวันนี้ทำงานสำเร็จไปแล้วกี่รอบ

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การควบคุมนาฬิกา (Timer Control)

- แสดงเวลานับถอยหลังขนาดใหญ่ในรูปแบบ นาที:วินาที (เช่น "25:00")
- ผู้ใช้สามารถกดปุ่ม "เริ่ม", "หยุดชั่วคราว" และ "รีเซ็ต" เพื่อควบคุมการนับเวลาได้
- ระบบมี 2 โหมดให้สลับ: "โฟกัส (25 นาที)" และ "พัก (5 นาที)" โดยผู้ใช้เลือกโหมดเองได้ (ความยาวเวลากำหนดตายตัวในโค้ด ไม่ต้องให้ผู้ใช้ปรับเอง)
- เมื่อนับเวลาครบ ระบบต้องแจ้งเตือนผู้ใช้ให้รับรู้อย่างชัดเจน (เช่น เปลี่ยนสีหน้าจอ หรือแสดงข้อความแจ้งเตือน)

### 2.2 การบันทึกชื่องาน (Create)

- ผู้ใช้สามารถพิมพ์ชื่องานที่กำลังจะโฟกัส แล้วกดเริ่มรอบโฟกัสได้ (รองรับการกด Enter)
- ระบบไม่อนุญาตให้เริ่มรอบโฟกัสโดยที่ชื่องานเป็นค่าว่าง
- รอบพักไม่จำเป็นต้องกรอกชื่องาน และให้บันทึกชื่อรายการเป็น "พัก"

### 2.3 การดูประวัติรอบการทำงาน (Read & Filter)

- เมื่อจบรอบโฟกัสหรือรอบพักแต่ละครั้ง ระบบบันทึกชื่อรายการ, ประเภทของรอบ และเวลาที่ใช้เข้าสู่ประวัติโดยอัตโนมัติ เรียงรายการล่าสุดไว้ด้านบน
- มีตัวกรองให้เลือกดู 3 มุมมอง: "ทั้งหมด", "เฉพาะรอบโฟกัส", "เฉพาะรอบพัก"
- แสดงตัวเลขสรุปแบบเรียลไทม์ เช่น "วันนี้ทำสำเร็จแล้ว 4 รอบ รวม 100 นาที"

### 2.4 การลบประวัติ (Delete)

- สามารถลบรายการประวัติทีละรายการได้
- มีปุ่ม "ล้างประวัติทั้งหมด" สำหรับลบประวัติทุกรายการพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ประวัติรอบการทำงานทั้งหมดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Time Formatting**: ตัวเลขวินาทีต้องแสดง 2 หลักเสมอ เช่น "09:05" ไม่ใช่ "9:5"
- **Double Click Guard**: การกดปุ่ม "เริ่ม" ซ้ำหลายครั้งต้องไม่ทำให้เวลาเดินเร็วขึ้นผิดปกติ
- **Long Text Handling**: กรณีชื่องานยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบจอ
- **Empty State**: หากยังไม่มีประวัติ ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีรอบการทำงาน เริ่มโฟกัสรอบแรกของคุณได้เลย!"
