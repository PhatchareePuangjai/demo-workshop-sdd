# Specification: Web Quiz Game Application (เกมตอบคำถาม)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันเกมตอบคำถามแบบเลือกตอบ เพื่อให้ผู้ใช้ทดสอบความรู้ของตัวเองอย่างสนุกสนาน รู้ผลคะแนนทันทีเมื่อจบเกม และเก็บสถิติคะแนนสูงสุดไว้เปรียบเทียบ

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเริ่มเกมและตอบคำถาม (Play)

- แสดงคำถามทีละข้อ พร้อมตัวเลือกคำตอบ 4 ข้อให้ผู้ใช้คลิกเลือก (ชุดคำถามเตรียมไว้ในโค้ด 5 ข้อ)
- เมื่อผู้ใช้เลือกคำตอบ ระบบต้องแจ้งทันทีว่าถูกหรือผิด โดยเน้นสีเขียวที่คำตอบที่ถูกต้อง และสีแดงเมื่อเลือกผิด
- หลังตอบแล้ว ผู้ใช้กดปุ่ม "ข้อถัดไป" เพื่อไปยังคำถามข้อต่อไป
- แสดงความคืบหน้าปัจจุบัน เช่น "ข้อที่ 3 จาก 5" และคะแนนสะสมแบบเรียลไทม์

### 2.2 การดูผลและกรองคำถาม (Read & Filter)

- เมื่อตอบครบทุกข้อ ให้แสดงหน้าสรุปผล ได้แก่ คะแนนที่ได้, จำนวนข้อที่ถูก และเปอร์เซ็นต์ความถูกต้อง
- หน้าสรุปผลต้องแสดงข้อความให้กำลังใจตามระดับคะแนน เช่น ได้เกิน 80% แสดง "ยอดเยี่ยมมาก!"
- ในหน้าสรุปผลมีตัวกรองให้ทบทวนคำถาม 3 มุมมอง: "ทั้งหมด", "เฉพาะข้อที่ตอบถูก", "เฉพาะข้อที่ตอบผิด"

### 2.3 การเล่นซ้ำและตั้งค่า (Update)

- ผู้ใช้สามารถกดปุ่ม "เล่นอีกครั้ง" เพื่อเริ่มเกมใหม่ โดยคะแนนและสถานะทุกอย่างถูกรีเซ็ต
- ระบบต้องป้องกันไม่ให้ผู้ใช้เลือกคำตอบซ้ำในข้อเดิมหลังจากตอบไปแล้ว

### 2.4 การจัดการสถิติ (Delete)

- แสดงคะแนนสูงสุดที่เคยทำได้ไว้ที่หน้าเริ่มเกมและหน้าสรุปผล
- มีปุ่ม "ล้างคะแนนสูงสุด" สำหรับรีเซ็ตสถิติ

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- คะแนนสูงสุดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: ปุ่มตัวเลือกคำตอบต้องมีขนาดใหญ่พอให้กดง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Progress Indicator**: ควรมีแถบความคืบหน้า (Progress Bar) แสดงว่าเล่นไปแล้วกี่เปอร์เซ็นต์ของเกม
- **Long Text Handling**: กรณีคำถามหรือตัวเลือกยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบจอ
- **Empty State**: หากยังไม่เคยเล่นจบสักครั้ง ให้แสดงข้อความในส่วนสถิติ เช่น "ยังไม่มีคะแนนสูงสุด เริ่มเล่นเกมแรกของคุณได้เลย!"
