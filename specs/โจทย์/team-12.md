# Specification: Web Recipe Box Application (คลังสูตรอาหาร)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับเก็บสูตรอาหารส่วนตัว เพื่อช่วยให้ผู้ใช้จดวัตถุดิบไว้ในที่เดียว ค้นหาเมนูที่อยากทำได้อย่างรวดเร็ว และเก็บเมนูโปรดไว้ทำซ้ำ

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มสูตรอาหาร (Create)

- ผู้ใช้สามารถกรอกชื่อเมนู, ประเภทอาหาร (เช่น "อาหารคาว", "ของหวาน", "เครื่องดื่ม"), เวลาที่ใช้ทำ (นาที) และรายการวัตถุดิบ แล้วกดบันทึกได้
- รายการวัตถุดิบรับข้อมูลแบบหลายบรรทัด และต้องถูกแสดงผลเป็นลิสต์รายข้อ
- ระบบไม่อนุญาตให้บันทึกสูตรที่ชื่อเมนูว่าง หรือไม่มีวัตถุดิบเลย

### 2.2 การดู ค้นหา และกรองสูตร (Read, Search & Filter)

- แสดงสูตรอาหารเป็นการ์ด โดยการ์ดแสดงเฉพาะชื่อเมนู ประเภท และเวลาที่ใช้ทำ
- ผู้ใช้สามารถคลิกที่การ์ดเพื่อขยายดูรายการวัตถุดิบทั้งหมดได้
- มีช่องค้นหาที่กรองสูตรจากชื่อเมนูได้ทันทีขณะพิมพ์
- มีตัวกรองให้เลือกดูตามประเภท: "ทั้งหมด", "อาหารคาว", "ของหวาน", "เครื่องดื่ม"
- แสดงตัวเลขสรุปแบบเรียลไทม์ เช่น "มีสูตรทั้งหมด 8 เมนู (เมนูโปรด 3 เมนู)"

### 2.3 การแก้ไขและทำเครื่องหมาย (Update)

- ผู้ใช้สามารถกดปุ่มรูปหัวใจเพื่อทำเครื่องหมาย "เมนูโปรด" และเมนูโปรดต้องแสดงสัญลักษณ์ที่เห็นชัดเจนบนการ์ด
- ผู้ใช้สามารถแก้ไขข้อมูลของสูตรที่บันทึกไว้แล้วได้ทุกช่อง
- การ์ดต้องแสดงป้ายกำกับสีตามประเภทอาหารเพื่อให้แยกแยะได้ง่าย

### 2.4 การลบสูตร (Delete)

- สามารถลบสูตรอาหารทีละรายการได้ โดยมีการถามยืนยันก่อนลบ
- มีปุ่ม "ล้างสูตรทั้งหมด" สำหรับลบทุกสูตรพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลสูตรอาหารทั้งหมดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: การ์ดต้องเรียงหลายคอลัมน์บนคอมพิวเตอร์ และเรียงคอลัมน์เดียวบนสมาร์ตโฟน
- **No Search Result**: หากค้นหาแล้วไม่พบสูตรที่ตรงกัน ต้องแสดงข้อความแจ้ง เช่น "ไม่พบสูตรอาหารที่ค้นหา"
- **Long Text Handling**: กรณีชื่อเมนูหรือชื่อวัตถุดิบยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบการ์ด
- **Empty State**: หากยังไม่มีสูตรอาหาร ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีสูตรอาหาร เริ่มบันทึกเมนูแรกของคุณได้เลย!"
