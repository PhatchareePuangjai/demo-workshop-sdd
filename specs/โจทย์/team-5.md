# Specification: Web Movie Watchlist Application (รายการหนังที่อยากดู)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับเก็บรายชื่อหนังหรือซีรีส์ที่อยากดู เพื่อช่วยให้ผู้ใช้ไม่ลืมเรื่องที่สนใจ ติดตามว่าดูจบไปแล้วเรื่องไหน และให้คะแนนความชอบของแต่ละเรื่องได้

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มรายการ (Create)

- ผู้ใช้สามารถกรอกชื่อเรื่อง, แนวหนัง (เช่น แอ็กชัน, ตลก, สยองขวัญ) และปีที่ฉาย แล้วกดเพิ่มเข้าสู่ลิสต์ได้
- ระบบไม่อนุญาตให้เพิ่มรายการที่ชื่อเรื่องเป็นค่าว่าง

### 2.2 การดู ค้นหา และกรองรายการ (Read, Search & Filter)

- แสดงรายการเป็นการ์ด เรียงลำดับจากรายการล่าสุดไว้ด้านบน
- มีช่องค้นหาที่กรองรายการตามชื่อเรื่องได้ทันทีขณะพิมพ์
- มีตัวกรองให้เลือกดู 3 มุมมอง: "ทั้งหมด", "ยังไม่ได้ดู", "ดูจบแล้ว"
- แสดงตัวเลขสรุปแบบเรียลไทม์ เช่น "ดูจบแล้ว 5 เรื่อง เหลืออีก 8 เรื่อง"

### 2.3 การแก้ไขและให้คะแนน (Update)

- ผู้ใช้สามารถกดปุ่มเพื่อสลับสถานะระหว่าง "ดูจบแล้ว" และ "ยังไม่ได้ดู"
- เรื่องที่ดูจบแล้วต้องแสดงผลให้ต่างจากเรื่องที่ยังไม่ได้ดูอย่างชัดเจน (เช่น ติดป้ายกำกับหรือปรับสีการ์ด)
- ผู้ใช้สามารถให้คะแนนความชอบแบบ 1 ถึง 5 ดาวกับเรื่องที่ดูจบแล้วได้
- ผู้ใช้สามารถแก้ไขชื่อเรื่องและแนวหนังของรายการที่มีอยู่แล้วได้

### 2.4 การลบรายการ (Delete)

- สามารถลบรายการทีละเรื่องได้
- มีปุ่ม "ล้างรายการที่ดูจบแล้ว" สำหรับลบเรื่องที่ดูจบทั้งหมดพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลรายการหนังและคะแนนทั้งหมดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: การ์ดต้องเรียงหลายคอลัมน์บนคอมพิวเตอร์ และเรียงคอลัมน์เดียวบนสมาร์ตโฟน
- **No Search Result**: หากค้นหาแล้วไม่พบเรื่องที่ตรงกัน ต้องแสดงข้อความแจ้ง เช่น "ไม่พบเรื่องที่ค้นหา"
- **Long Text Handling**: กรณีชื่อเรื่องยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบการ์ด
- **Empty State**: หากยังไม่มีรายการใด ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีหนังในลิสต์ เพิ่มเรื่องแรกที่อยากดูได้เลย!"
