# Specification: Web Grocery Shopping List Application (รายการซื้อของพร้อมงบประมาณ)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับจดรายการซื้อของก่อนไปตลาดหรือซูเปอร์มาร์เก็ต เพื่อช่วยให้ผู้ใช้ซื้อของครบตามที่ตั้งใจ และควบคุมค่าใช้จ่ายไม่ให้เกินงบที่ตั้งไว้

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มรายการ (Create)

- ผู้ใช้สามารถกรอกชื่อสินค้า, จำนวนชิ้น และราคาต่อชิ้น แล้วกดเพิ่มเข้าสู่ลิสต์ได้ (รองรับการกด Enter)
- ผู้ใช้สามารถเลือกหมวดหมู่ของสินค้าได้ เช่น "ของสด", "ของใช้", "ขนม", "เครื่องดื่ม"
- ระบบไม่อนุญาตให้เพิ่มสินค้าที่ชื่อว่าง หรือจำนวน/ราคาที่ไม่ใช่ตัวเลขที่มากกว่า 0

### 2.2 การดูและกรองรายการ (Read & Filter)

- แสดงรายการสินค้าโดยจัดกลุ่มตามหมวดหมู่ เพื่อให้เดินซื้อของได้สะดวก
- มีตัวกรองให้เลือกดู 3 มุมมอง: "ทั้งหมด", "ยังไม่ได้หยิบ", "หยิบแล้ว"
- แสดงตัวเลขสรุปแบบเรียลไทม์ ได้แก่ จำนวนสินค้าที่ยังไม่ได้หยิบ และราคารวมของทั้งลิสต์

### 2.3 การแก้ไขและเปลี่ยนสถานะ (Update)

- มี Checkbox หน้าแต่ละรายการเพื่อสลับสถานะ "หยิบแล้ว" หรือ "ยังไม่ได้หยิบ"
- รายการที่หยิบแล้วจะแสดงข้อความแบบขีดฆ่า (Strikethrough) และปรับสีให้จางลง
- ผู้ใช้สามารถแก้ไขชื่อสินค้า จำนวน และราคาของรายการที่มีอยู่แล้วได้ โดยราคารวมต้องคำนวณใหม่ทันที
- ผู้ใช้สามารถตั้งงบประมาณสูงสุดได้ และระบบต้องเตือนเมื่อราคารวมเกินงบที่ตั้งไว้

### 2.4 การลบรายการ (Delete)

- สามารถลบสินค้าทีละรายการได้
- มีปุ่ม "ล้างรายการที่หยิบแล้ว" สำหรับลบสินค้าที่หยิบครบแล้วทั้งหมดพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลรายการสินค้าและงบประมาณต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Number Formatting**: ราคาต้องแสดงคั่นหลักพันด้วยเครื่องหมายจุลภาคและมีทศนิยม 2 ตำแหน่ง เช่น "1,250.00 บาท"
- **Over Budget Warning**: เมื่อราคารวมเกินงบประมาณ ต้องแสดงยอดรวมเป็นสีแดงพร้อมข้อความเตือน
- **Long Text Handling**: กรณีชื่อสินค้ายาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบจอ
- **Empty State**: หากยังไม่มีสินค้าในลิสต์ ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ลิสต์ยังว่างอยู่ เพิ่มของชิ้นแรกที่ต้องซื้อได้เลย!"
