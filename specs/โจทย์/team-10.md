# Specification: Web Coffee Shop Order Application (ระบบสั่งเครื่องดื่มร้านกาแฟ)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับสั่งเครื่องดื่มในร้านกาแฟ เพื่อช่วยให้ลูกค้าเลือกเมนู ปรับตัวเลือก และเห็นราคารวมของออเดอร์ได้อย่างชัดเจนก่อนยืนยันการสั่ง

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเลือกเมนูใส่ตะกร้า (Create)

- แสดงเมนูเครื่องดื่มเป็นการ์ด อย่างน้อย 6 รายการ พร้อมชื่อเมนูและราคา (ข้อมูลเมนูเตรียมไว้ในโค้ด)
- ผู้ใช้สามารถเลือกประเภทของเครื่องดื่มก่อนใส่ตะกร้าได้ ได้แก่ ร้อน / เย็น / ปั่น
- ประเภทเย็นบวกเพิ่ม 5 บาท และประเภทปั่นบวกเพิ่ม 10 บาท จากราคาปกติ
- ระบบไม่อนุญาตให้ใส่ตะกร้าโดยที่ยังไม่ได้เลือกประเภท

### 2.2 การดูและกรองเมนู (Read & Filter)

- มีตัวกรองหมวดหมู่เมนูให้เลือกดู: "ทั้งหมด", "กาแฟ", "ชา", "อื่น ๆ"
- แสดงตะกร้าสินค้าพร้อมรายการที่เลือก จำนวน ตัวเลือก และราคารวมของแต่ละรายการ
- แสดงสรุปยอดแบบเรียลไทม์ ได้แก่ จำนวนแก้วทั้งหมด และราคารวมสุทธิของออเดอร์

### 2.3 การแก้ไขออเดอร์ (Update)

- ผู้ใช้สามารถกดปุ่ม "+" และ "−" เพื่อเพิ่มหรือลดจำนวนของแต่ละรายการในตะกร้าได้
- เมื่อจำนวนถูกลดจนเหลือ 0 ให้รายการนั้นถูกนำออกจากตะกร้าโดยอัตโนมัติ
- เมื่อกดปุ่ม "ยืนยันการสั่ง" ให้แสดงข้อความสรุปออเดอร์พร้อมยอดรวมสุทธิ แล้วล้างตะกร้าให้พร้อมสำหรับออเดอร์ถัดไป

### 2.4 การลบรายการ (Delete)

- สามารถลบรายการในตะกร้าทีละรายการได้
- มีปุ่ม "ล้างตะกร้า" สำหรับลบทุกรายการพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลตะกร้าสินค้าต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: การ์ดเมนูต้องเรียงหลายคอลัมน์บนคอมพิวเตอร์ และเรียงคอลัมน์เดียวบนสมาร์ตโฟน โดยตะกร้ายังเข้าถึงได้สะดวก
- **Number Formatting**: ราคาต้องแสดงคั่นหลักพันด้วยเครื่องหมายจุลภาคและมีทศนิยม 2 ตำแหน่ง เช่น "1,250.00 บาท"
- **Checkout Guard**: หากตะกร้าว่าง ปุ่ม "ยืนยันการสั่ง" ต้องกดไม่ได้หรือแจ้งเตือนผู้ใช้
- **Long Text Handling**: กรณีชื่อเมนูยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบการ์ด
- **Empty State**: หากตะกร้ายังว่าง ให้แสดงข้อความสั้น ๆ เช่น "ตะกร้ายังว่างอยู่ เลือกเครื่องดื่มแก้วโปรดของคุณได้เลย!"
