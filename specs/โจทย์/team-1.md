# Specification: Web Expense Tracker Application (บันทึกรายรับ-รายจ่าย)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับบันทึกรายรับและรายจ่ายประจำวัน เพื่อช่วยให้ผู้ใช้มองเห็นภาพรวมการเงินของตัวเองว่าเงินเข้าออกไปกับเรื่องใดบ้าง และเหลือเงินคงเหลือเท่าไร

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มรายการ (Create)

- ผู้ใช้สามารถกรอกรายละเอียดของรายการได้แก่ ชื่อรายการ, จำนวนเงิน, และประเภท (รายรับ / รายจ่าย) แล้วกดบันทึกเข้าสู่ลิสต์
- ผู้ใช้สามารถเลือกหมวดหมู่ของรายการได้ เช่น "อาหาร", "เดินทาง", "ช้อปปิ้ง", "อื่น ๆ"
- ระบบไม่อนุญาตให้บันทึกรายการที่ชื่อว่าง หรือจำนวนเงินไม่ใช่ตัวเลขที่มากกว่า 0

### 2.2 การดูและกรองรายการ (Read & Filter)

- แสดงรายการทั้งหมดเรียงจากรายการล่าสุดไว้ด้านบน พร้อมแยกสีรายรับ (เขียว) และรายจ่าย (แดง) ให้เห็นชัดเจน
- มีตัวกรองให้เลือกดู 3 มุมมอง: "ทั้งหมด", "เฉพาะรายรับ", "เฉพาะรายจ่าย"
- แสดงกล่องสรุปด้านบนแบบเรียลไทม์ 3 ค่า ได้แก่ รายรับรวม, รายจ่ายรวม และยอดคงเหลือ (รายรับ - รายจ่าย)

### 2.3 การแก้ไขรายการ (Update)

- ผู้ใช้สามารถแก้ไขชื่อรายการและจำนวนเงินของรายการที่บันทึกไว้แล้วได้
- เมื่อแก้ไขเสร็จ กล่องสรุปยอดทั้งหมดต้องคำนวณใหม่ทันที

### 2.4 การลบรายการ (Delete)

- สามารถลบรายการทีละรายการได้ โดยมีการถามยืนยันก่อนลบ
- มีปุ่ม "ล้างข้อมูลทั้งหมด" สำหรับลบทุกรายการพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลรายการทั้งหมดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Number Formatting**: จำนวนเงินต้องแสดงคั่นหลักพันด้วยเครื่องหมายจุลภาคและมีทศนิยม 2 ตำแหน่ง เช่น "1,250.00 บาท"
- **Negative Balance**: หากยอดคงเหลือติดลบ ต้องแสดงเป็นสีแดงเพื่อเตือนผู้ใช้
- **Long Text Handling**: กรณีชื่อรายการยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบจอ
- **Empty State**: หากยังไม่มีรายการใด ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีรายการ เริ่มบันทึกรายรับ-รายจ่ายแรกของคุณได้เลย!"
