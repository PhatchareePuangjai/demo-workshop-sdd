# Specification: Web Daily Water & Health Tracker Application (ติดตามการดื่มน้ำประจำวัน)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับบันทึกปริมาณน้ำที่ดื่มในแต่ละวัน เพื่อช่วยให้ผู้ใช้ดื่มน้ำได้ครบตามเป้าหมายที่ตั้งไว้ และเห็นความคืบหน้าของตัวเองอย่างชัดเจน

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การบันทึกการดื่มน้ำ (Create)

- มีปุ่มลัดสำหรับบันทึกปริมาณที่ใช้บ่อย ได้แก่ 100 มล., 250 มล. และ 500 มล. กดครั้งเดียวบันทึกได้ทันที
- ผู้ใช้สามารถกรอกปริมาณเองเป็นตัวเลขแล้วกดบันทึกได้ (รองรับการกด Enter)
- ทุกรายการที่บันทึกต้องเก็บเวลาที่บันทึกไว้ด้วย เช่น "14:35"
- ระบบไม่อนุญาตให้บันทึกปริมาณที่เป็นค่าว่าง หรือไม่ใช่ตัวเลขที่มากกว่า 0

### 2.2 การดูความคืบหน้าและกรอง (Read & Filter)

- แสดงแถบความคืบหน้า (Progress Bar) หรือรูปแก้วน้ำที่เติมขึ้นตามสัดส่วนของเป้าหมายที่ดื่มไปแล้ว
- แสดงตัวเลขสรุปแบบเรียลไทม์ เช่น "ดื่มแล้ว 1,250 / 2,000 มล. (63%) เหลืออีก 750 มล."
- แสดงประวัติการดื่มของวันนี้เป็นรายการ เรียงจากรายการล่าสุดไว้ด้านบน
- มีตัวกรองให้เลือกดูประวัติ 3 มุมมอง: "ทั้งวัน", "ช่วงเช้า (ก่อน 12:00)", "ช่วงบ่าย-เย็น (ตั้งแต่ 12:00)"

### 2.3 การแก้ไขและตั้งเป้าหมาย (Update)

- ผู้ใช้สามารถตั้งเป้าหมายการดื่มน้ำต่อวันเองได้ (หน่วยเป็นมิลลิลิตร) และแถบความคืบหน้าต้องคำนวณใหม่ทันที
- ผู้ใช้สามารถแก้ไขปริมาณของรายการที่บันทึกไว้แล้วได้
- เมื่อดื่มครบตามเป้าหมาย ระบบต้องแสดงข้อความแสดงความยินดีให้เห็นชัดเจน

### 2.4 การลบรายการ (Delete)

- สามารถลบรายการที่บันทึกไว้ทีละรายการได้ และยอดรวมต้องลดลงทันที
- มีปุ่ม "เริ่มวันใหม่" สำหรับล้างประวัติทั้งหมดของวันโดยที่ยังเก็บค่าเป้าหมายไว้

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลการดื่มน้ำและค่าเป้าหมายต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Over Goal Case**: หากดื่มเกินเป้าหมาย แถบความคืบหน้าต้องไม่ล้นเกิน 100% แต่ยังแสดงปริมาณจริงที่ดื่มไปได้
- **Number Formatting**: ปริมาณน้ำต้องแสดงคั่นหลักพันด้วยเครื่องหมายจุลภาค เช่น "2,000 มล."
- **Long Text Handling**: ข้อความสรุปต้องขึ้นบรรทัดใหม่อย่างสวยงามบนหน้าจอแคบ ไม่ล้นหลุดขอบจอ
- **Empty State**: หากยังไม่มีการบันทึกในวันนี้ ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่ได้ดื่มน้ำเลยวันนี้ เริ่มแก้วแรกของคุณได้เลย!"
