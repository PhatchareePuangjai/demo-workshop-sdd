# Specification: Web Flashcard Vocabulary Application (บัตรคำศัพท์)

## 0. ขอบเขตของงาน (Scope)

- เว็บหน้าเดียว (Single Page) ใช้ HTML / CSS / JavaScript เท่านั้น ไม่ใช้ Framework และไม่มี Backend
- ระยะเวลาในการพัฒนา 1 ชั่วโมง 15 นาที

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันบัตรคำศัพท์ (Flashcard) เพื่อช่วยให้ผู้ใช้สร้างชุดคำศัพท์ของตัวเองและทบทวนความจำได้อย่างมีประสิทธิภาพ ด้วยการพลิกบัตรดูคำแปลและติดตามคำที่ยังจำไม่ได้

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มบัตรคำ (Create)

- ผู้ใช้สามารถกรอก "คำศัพท์" (ด้านหน้า) และ "คำแปล/ความหมาย" (ด้านหลัง) แล้วกดเพิ่มเข้าสู่ชุดบัตรได้
- ระบบไม่อนุญาตให้เพิ่มบัตรที่ด้านหน้าหรือด้านหลังเป็นค่าว่าง

### 2.2 การทบทวนและกรอง (Read & Review)

- มีโหมดทบทวน แสดงบัตรทีละใบ พร้อมปุ่ม "ก่อนหน้า" และ "ถัดไป" เพื่อเลื่อนดูบัตร
- คลิกที่บัตรเพื่อพลิกสลับระหว่างด้านคำศัพท์และด้านคำแปล
- แสดงตำแหน่งปัจจุบันของบัตรที่กำลังดู เช่น "บัตรที่ 3 จาก 10"
- มีตัวกรองให้เลือกทบทวน 3 มุมมอง: "ทั้งหมด", "เฉพาะที่จำได้แล้ว", "เฉพาะที่ยังจำไม่ได้"

### 2.3 การเปลี่ยนสถานะและแก้ไข (Update)

- ในแต่ละบัตรมีปุ่มสำหรับทำเครื่องหมาย "จำได้แล้ว" หรือ "ยังจำไม่ได้"
- บัตรที่ทำเครื่องหมายว่าจำได้แล้วต้องแสดงสัญลักษณ์หรือสีที่แตกต่างจากบัตรอื่นอย่างชัดเจน
- ผู้ใช้สามารถแก้ไขคำศัพท์และคำแปลของบัตรที่มีอยู่แล้วได้
- แสดงตัวเลขสรุปความคืบหน้าแบบเรียลไทม์ เช่น "จำได้แล้ว 4 จาก 10 คำ"

### 2.4 การลบบัตร (Delete)

- สามารถลบบัตรคำทีละใบได้
- มีปุ่ม "ล้างบัตรที่จำได้แล้ว" สำหรับลบบัตรที่ทำเครื่องหมายว่าจำได้แล้วทั้งหมดพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลบัตรคำและสถานะการจำทั้งหมดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Flip Animation**: การพลิกบัตรควรมีการเคลื่อนไหว (Transition) ที่ลื่นไหล ไม่กระตุก
- **Long Text Handling**: กรณีคำแปลยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อยู่ในกรอบบัตรอย่างสวยงาม ไม่ล้นหลุดขอบ
- **Boundary Case**: เมื่อดูบัตรใบสุดท้ายแล้วกด "ถัดไป" ต้องไม่เกิดข้อผิดพลาด (จะวนกลับใบแรกหรือปิดปุ่มก็ได้)
- **Empty State**: หากยังไม่มีบัตรคำ ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ยังไม่มีบัตรคำ เริ่มสร้างคำศัพท์แรกของคุณได้เลย!"
