# Specification: Web Todo List Application

## 1. Goal / Business Value (เป้าหมาย)

สร้างเว็บแอปพลิเคชันสำหรับจัดการรายการงานประจำวัน (Todo List) เพื่อช่วยให้ผู้ใช้สามารถบันทึก วางแผน และติดตามงานที่ต้องทำได้อย่างรวดเร็วและไม่มีตกหล่น

## 2. User Capabilities & Requirements (สิ่งที่ผู้ใช้งานทำได้)

### 2.1 การเพิ่มรายการ (Create)

- ผู้ใช้สามารถพิมพ์ชื่อรายการงานใหม่และกดเพิ่มเข้าสู่ลิสต์ได้ทันที (รองรับการกด Enter)
- ระบบไม่อนุญาตให้เพิ่มรายการที่เป็นค่าว่าง (Empty Text)

### 2.2 การดูและกรองรายการ (Read & Filter)

- แสดงรายการงานเรียงลำดับจากรายการล่าสุดไว้ด้านบน
- มีตัวกรอง (Filter) ให้เลือกดู 3 มุมมอง: "ทั้งหมด (All)", "กำลังทำ (Active)", "เสร็จแล้ว (Completed)"
- แสดงตัวเลขสรุปจำนวนงานที่ยังทำไม่เสร็จทันที (เช่น "เหลืออีก 3 รายการ")

### 2.3 การแก้ไขและเปลี่ยนสถานะ (Update)

- มี Checkbox หน้าแต่ละรายการเพื่อสลับสถานะ "เสร็จแล้ว" หรือ "ยังไม่เสร็จ"
- รายการที่ทำเสร็จแล้วจะแสดงข้อความแบบขีดฆ่า (Strikethrough) และปรับสีให้จางลง
- ผู้ใช้สามารถแก้ไขข้อความในรายการที่มีอยู่แล้วได้

### 2.4 การลบรายการ (Delete)

- สามารถลบรายการงานที่ไม่ต้องการทีละรายการได้
- มีปุ่ม "ล้างรายการที่เสร็จแล้ว (Clear Completed)" สำหรับลบงานที่ทำเสร็จทั้งหมดพร้อมกัน

### 2.5 การคงอยู่ของข้อมูล (Persistence)

- ข้อมูลรายการงานทั้งหมดต้องไม่สูญหายเมื่อปิดหรือรีเฟรชเบราว์เซอร์

## 3. User Experience & Edge Cases (ประสบการณ์ใช้งานและเงื่อนไขพิเศษ)

- **Responsive Design**: หน้าตาแอปพลิเคชันต้องปรับการแสดงผลให้อ่านและใช้งานง่ายทั้งบนคอมพิวเตอร์และสมาร์ตโฟน
- **Long Text Handling**: กรณีชื่อรายการยาวมาก ข้อความต้องขึ้นบรรทัดใหม่อย่างสวยงาม ไม่ล้นหลุดขอบจอ
- **Empty State**: หากไม่มีรายการงานเหลืออยู่ ให้แสดงข้อความต้อนรับสั้น ๆ เช่น "ไม่มีรายการงานในขณะนี้ เริ่มเพิ่มงานแรกของคุณได้เลย!"
