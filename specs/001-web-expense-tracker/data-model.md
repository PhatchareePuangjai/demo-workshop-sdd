# Data Model: Web Expense Tracker

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md) | **Research**: [research.md](./research.md)

The `state` object in `app.js` is the single source of truth (Principle VI). Only `items` is persisted; everything else is session-only.

## `state`

| Field | Type | Persisted | Meaning |
|---|---|---|---|
| `items` | `Entry[]` | Yes | All entries, **newest first** (array order is the display order) |
| `filter` | `'all' \| 'income' \| 'expense'` | No | Current list view; starts as `'all'` (FR-008) |
| `editing` | `EditSession \| null` | No | The row currently being edited, or `null` |

## Entry

One income or expense record. Maps to the spec's **Entry (รายการ)**.

| Field | Type | Rules | Notes |
|---|---|---|---|
| `id` | string | unique, non-empty | Generated by the base `createId()`; used to find the row for edit/delete |
| `name` | string | trimmed, non-empty (FR-003) | Long text allowed; rendered HTML-escaped (FR-020) |
| `amountSatang` | integer | safe integer, `> 0` (FR-004) | Baht × 100 after rounding to 2 decimals; see research R2 |
| `type` | `'income' \| 'expense'` | required | Fixed at creation (FR-013) |
| `category` | `'food' \| 'travel' \| 'shopping' \| 'other'` | required, default `'other'` (FR-002) | Fixed at creation (FR-013) |
| `createdAt` | ISO-8601 string | required | Set at creation; never changed by edit |

**Display labels** (Thai UI): `income` → รายรับ, `expense` → รายจ่าย; `food` → อาหาร, `travel` → เดินทาง, `shopping` → ช้อปปิ้ง, `other` → อื่น ๆ.

**Ordering**: New entries are inserted at index 0 (`unshift`). Editing mutates an entry in place, so its position never changes (FR-006, FR-013).

## Summary (derived, never stored)

Computed by `render()` from **all** `state.items`, independent of `state.filter` (FR-009, FR-010).

| Value | Formula |
|---|---|
| `incomeSatang` | Σ `amountSatang` where `type === 'income'` |
| `expenseSatang` | Σ `amountSatang` where `type === 'expense'` |
| `balanceSatang` | `incomeSatang − expenseSatang` |

Balance is styled as negative only when `balanceSatang < 0` (FR-019); exactly `0` is neutral.

## Visible list (derived)

`getVisibleItems()`: `'all'` → every item; `'income'` / `'expense'` → items with that `type`. Order is preserved.

## EditSession (transient)

| Field | Type | Meaning |
|---|---|---|
| `id` | string | The entry being edited |
| `name` | string | Current text in the edit name field (starts as the entry's `name`) |
| `amount` | string | Current text in the edit amount field (starts as baht value with 2 decimals) |
| `error` | string | Validation message shown in the row; `''` when none |

### Edit lifecycle

```text
        click "แก้ไข" on row X                        submit (valid)
(none) ──────────────────────────▶ editing X ────────────────────────▶ (none)
   ▲                                  │  │            entry X updated: name + amountSatang only
   │   "ยกเลิก" / any other action    │  │ submit (invalid)
   └──────────────────────────────────┘  └──▶ editing X, error set, typed values kept
```

- Starting an edit on row Y while X is being edited replaces the session (X's draft is discarded).
- "Any other action" = a successful add, a confirmed delete, a filter change, or a confirmed clear-all. A rejected add (validation error) or a cancelled confirmation changes nothing, so the edit stays open.
- A page reload always yields `editing = null` (not persisted).

## Validation rules (shared by create and edit — FR-003, FR-004, FR-012)

| Input | Rule | Message (Thai) |
|---|---|---|
| name | `name.trim()` must be non-empty | กรุณากรอกชื่อรายการ |
| amount | `Number(raw)` finite; `Math.round(n * 100)` is a safe integer and `> 0` | กรุณากรอกจำนวนเงินเป็นตัวเลขที่มากกว่า 0 |

Name is checked first; if both are invalid, the name message is shown. Create shows the message in `#form-error`; edit shows it in the row's error line (`EditSession.error`).

## State transitions summary

| Action | Effect on `state` | Persisted? |
|---|---|---|
| Add (valid) | `items.unshift(entry)`; `editing = null` | Yes |
| Add (invalid) | none (message only) | No |
| Edit save (valid) | update `name`, `amountSatang` on the entry; `editing = null` | Yes |
| Edit save (invalid) | `editing.error` set, typed values kept | No |
| Edit cancel | `editing = null` | No |
| Delete (confirmed) | remove entry; `editing = null` | Yes |
| Clear all (confirmed, items > 0) | `items = []`; `editing = null` | Yes |
| Filter click | `filter = value`; `editing = null` | No (filter not persisted) |
