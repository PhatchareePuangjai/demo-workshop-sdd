# demo-workshop-sdd

## Deploy (Vercel)

Repo นี้เชื่อมกับ Vercel แล้ว ทุก branch ที่ `git push` จะได้ URL preview อัตโนมัติ ไม่ต้องตั้งค่าเพิ่ม:

```
demo-workshop-sdd-git-<ชื่อ branch>-<scope>.vercel.app
```

เช่น push ขึ้น branch `team-a` → `demo-workshop-sdd-git-team-a-<scope>.vercel.app`

URL จะอัปเดตตาม commit ล่าสุดของ branch นั้นเสมอ ไม่ต้องกด deploy เอง
